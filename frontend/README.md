# Frontend - Api-Banco

Interface moderna e intuitiva para o gerenciamento de operações bancárias.

## 🚀 Tecnologias
- **React 19**
- **Vite** para um ambiente de desenvolvimento ultra-rápido
- **TypeScript** para maior segurança no código
- **Axios** para consumo de APIs com tratamento de erros
- **React Router 7** para navegação fluida entre páginas
- **CSS Vanilla** com design customizado e moderno

## 📋 Pré-requisitos
- Node.js v18+
- Backend em execução na porta `3000`

## ⚙️ Instalação e Configuração

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

3. Acesse no navegador:
   `http://localhost:5173`

## 🛠️ Scripts Disponíveis
- `npm run dev`: Inicia o ambiente de desenvolvimento.
- `npm run build`: Cria a versão otimizada para produção na pasta `dist`.
- `npm run preview`: Visualiza localmente o build de produção.
- `npm run lint`: Executa a verificação de linting do código.

## 🎨 Design System
O projeto utiliza um sistema de cores baseadas em variáveis CSS (`--primary`, `--success`, etc.), facilitando a customização total da identidade visual através do arquivo `src/styles/global.css`.
